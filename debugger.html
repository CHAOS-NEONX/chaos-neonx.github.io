A TUI Debugger
Built for Embedded Systems

Compact Debugger (also known as CHAOS Debugger / CD) is an embedded-focused debugger written in pure C. With an approximate footprint of ~500KB, it stays lightweight while still providing a productive, visual terminal UI for real embedded workflows.

Core Features

Highlights · what makes CD different

Heterogeneous Multi-core Debugging

Debug multi-core targets (e.g., RP2040) with fast, intuitive core switching.

Lightweight, Pure C

Small and efficient, with no external dependencies beyond basic system libraries.

Built-in Code Browser

Navigate headers and functions instantly—designed for real embedded workflows.

ELF-aware Workflow

Analyze ELF to browse related files, export BIN automatically, and download to target.

Direct CMSIS-DAP / J-Link Integration

Connect and debug without extra layers—optimized for CMSIS-DAP / J-Link based setups.

Chip Database + Auto-complete

Built-in device database with smart completion for full part numbers.

No-source Library Debugging

Auto-fallback to instruction view while preserving symbols, plus branch/jump insights and “run to next C statement”.

Built-in RTT Terminal

Integrated RTT terminal with configurable channels and content ranges.

Capabilities

Operations · stepping · breakpoints · inspection

  • Sessions: ATTACH to a target and CLOSE (disconnect) at any time.
  • Views: switch seamlessly between ASM, C, and MIX in the same view.
  • Stepping: instruction-level stepping and C-statement stepping, including mixed Step Into / Step Out.
  • Breakpoints: set by ADDRESS / FILE:LINE / SYMBOL, with both graphical and command-line configuration.
  • Conditional breaks: register breakpoints and advanced data breakpoints (watchpoints).
  • Run-To: run-to by ADDRESS / FILE:LINE / SYMBOL, with both graphical and command-line workflows.
  • Live inspection: continuously refreshed WATCH window and MEMORY view.
  • Stack analysis: advanced stack analyzer with call-frame selection and synchronized locals + stack viewers.
  • History: the INFO area keeps historical records for quick backtracking.

Functions

CLI cheatsheet · grouped commands

Device & Session

list devices              - list devices
device <num|name>         - set device
if                        - interface selection
connect                   - connect to previously selected device
attach                    - connect to target
close                     - disconnect from target

Pick a device, choose interface, then attach to start a session.

Symbols & ELF

symfile <file>               - load ELF/DWARF or map/nm
elf <path>                   - set elf path
download <addr> / dl         - download elf

Load debug symbols and set ELF path before downloading.

Run & Step

g                         - go / run
i                         - step one instruction
step                      - step
s                         - step one C line
si                        - step into the callee
so                        - step out to next C statement
nextc                     - step to next C statement
rt <sym|file:line|*A>     - run to location
rstart                    - restart cpu core
rstarth                   - system reset and stop at Reset_Handler

Use rt for quick run-to and nextc/so for C-statement flows.

Inspect & Memory

r                            - print registers
set reg <REG> <VAL>          - set register value
mr <addr> <len>              - memory read
mw <addr> <len>              - memory write
watch add <expr>             - watch add expr
watch del <expr>             - watch del expr
watch list                   - watch list
locals                       - show locals/args of current frame
stack                        - advanced stack viewer
bt / where                   - show call stack

Typical loop: r → locals → mr/watch → bt.

Breakpoints

break <sym|file:line|*A>     - set breakpoint
bl / listbp                  - list breakpoint(s)
bc <idx|addr|all>            - clear breakpoint(s)
bh                           - breakpoint history

Set by symbol / file:line / address (with *A).

Data Breakpoints

dw set <addr>                - data breakpoint set
dw clear <addr>              - data breakpoint(s) clear
dw list                      - data breakpoint(s) list

For write/read triggers on addresses (target dependent).

Hardware Watchpoints

watchpoint <addr> [sz]       - hardware watchpoint
unwatch <addr>               - remove watchpoint
info watchpoints             - list watchpoints

Use [sz] when your core requires a watch size.

RTT & Tools

rtt [auto/ch/ram/clear/help]    - RTT: one-shot/keep/ram/auto
sv                              - source-code viewer

sv opens the code viewer; rtt manages terminal streaming modes.

Help & Quit

help / ?                     - show help
q                            - quit debugger

Quick discovery: type ? any time.
